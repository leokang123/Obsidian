# 첫번째 수업

#대학교 #모바일컴퓨팅

전학기 네트워크 수업은 큰 틀에서 어떻게 구성되고 어떻게 작동하는지 큰 구성에서 몇몇 요소들을 공부한거고

이 수업에서는 구체적인 프로토콜들에 대해 공부를 한다

서로 커뮤니케이션을 하기 위해서는 규칙이 필요하다 → 프로토콜

왜 모바일 컴퓨팅이야? → 원래 개설 목적은 모바일 컴퓨팅과 관련된 공부를 하려했지만, 학생과 교수와의 갭 때문에 **인터넷 프로토콜**만 배운다고 한다.

이쪽 세계(IT 업, 네트워크 관련) 에서 현 상황에대한 이해는 매우 중요하다 → 유선 환경에서 무선환경으로 이전했듯이 앞으로 어떻게 변화할지 생각해야한다
