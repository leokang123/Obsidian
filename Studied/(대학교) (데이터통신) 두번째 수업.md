### Data Flow

![[Pasted image 20240905154700.png]]

- Simplex: 단방향으로 데이터를 통신할수 있는 것(티비, 라디오 등)
- Half-duplex: 양방향으로 통신이 되지만 동시에는 되지않는것(무전기 등)
- Full-duplex: 양방향으로 통신이 동시에 되는 것(휴대폰 전화)

### Network Types

- Local Area Network (LAN)
	- 사무실, 빌딩 수준
	- WLAN(wireless lan)과 wifi 는 같은걸까? → 다르다고 한다
- Wide Area Network (WAN)
	- 수백키로미터 이상
	- 휴대전화망, 인터넷
- Metropolitan Area Network (MAN)
	- 수십킬로미터 이내
	- 대학캠퍼스 규모

> PAN (Personal Area Network) : 개인 공간 수준의 네트워크

### Internet

network layer에서는 ip를 사용하고 transport layer에서는 tcp/udp를 사용하는 것들의 네트워크

> layer 1, 2 는 하드웨어적으로 지원을하고, layer3, 4, 5는 소프트웨어적으로 지원한다
